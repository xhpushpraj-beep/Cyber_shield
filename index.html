🛡️ About Cyber Shield

Cyber Shield is a cybersecurity awareness and threat detection website designed to help users understand common online risks.

The website provides simple educational tools for password security, URL safety, phishing awareness, cybersecurity quizzes and safe online habits.

This project is developed as an academic project to promote cybersecurity awareness among students and internet users.

🔒 Cybersecurity Safety Tips

Follow these basic habits to stay safer online.

🔑 Use Strong Passwords

Use long and unique passwords for your important accounts.

🔐 Enable 2FA

Enable two-factor authentication whenever it is available.

🚫 Never Share OTP

Never share OTPs, PINs or passwords with anyone.

🎣 Watch for Phishing

Be careful with unexpected emails, messages and links.

🌐 Check URLs

Carefully check website addresses before entering personal information.

🔄 Update Software

Keep your operating system and applications updated.
